# Digital Shamans Suite

Public Windows installers and update manifests for Digital Shamans Suite.

Download the Suite Manager or an individual application from [Releases](https://github.com/DigitalShamans/DS-Suite-Releases/releases). Apps install and open independently. The offline Suite Manager installer includes the three initial application installers.

| Application | Initial version |
| --- | --- |
| Suite Manager | 0.01 |
| Image Processor | 1.20 |
| Spreadsheet Editor | 0.02 |
| Cost Estimation Calculator | 1.18 |

The stable update feed is `https://github.com/DigitalShamans/DS-Suite-Releases/releases/latest/download/suite-feed.json`. This link becomes available when the first release is published.

Application source is maintained separately. Company data, documents, profiles, diagnostics and credentials do not belong in this repository. Use each app's included notices for third-party license information.

The initial Windows preview was cross-compiled and checked through automated tests and extracted-installer verification. Native Windows acceptance and a genuine higher-version update test are still required. Code signing is deferred.
